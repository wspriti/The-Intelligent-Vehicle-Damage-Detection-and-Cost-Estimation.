# Intelligent Vehicle Damage Detection and Cost Estimation

## Project Description
An AI-based system that detects vehicle damage from uploaded images using Deep Learning and YOLOv8.

## Features
- Vehicle damage detection
- Scratch, dent, crack and broken-part identification
- Damage severity classification
- Repair cost estimation
- Insurance claim report generation

## Technologies Used
- Python
- Deep Learning
- CNN
- YOLOv8
- Computer Vision
- FastAPI

## Project Objective
To automate vehicle damage assessment and repair cost estimation, making the insurance claim process easier and faster.
